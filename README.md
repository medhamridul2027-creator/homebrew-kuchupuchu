# Kuchu Puchu for Homebrew

```
brew tap medhamridul2027-creator/kuchupuchu
brew trust medhamridul2027-creator/kuchupuchu
brew install --cask kuchu-puchu
```

Installs the Mac app (Apple Silicon, macOS 14 or later) from https://kuchupuchu.me/. Homebrew asks you to trust any tap that is not its own once (the `brew trust` line). This early beta is not notarized by Apple yet, so macOS may ask you to confirm the first time you open it.
